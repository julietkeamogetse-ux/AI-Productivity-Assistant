# AI Workplace Assistant
 
A modern, full-featured React dashboard designed to eliminate daily work administrative friction using AI automation. Built with React 18, Tailwind CSS, and Lucide React icons.
 
🔗 **web Application Link:** https://claude.ai/public/artifacts/d0328552-4c51-4ad5-9af5-dc367cc69daa
 
---
 
## 🌟 Key Features
 
* **Smart Email Generator:** Draft tailored emails by audience (Client, Colleague, Executive) and tone (Formal, Friendly, Direct, Persuasive) with one-click copy options.
* **Meeting Notes Summarizer:** Transform raw transcripts into structured summaries, key points, key decisions, and actionable tasks with assigned owners and deadlines.
* **AI Task Planner:** Priority matrix scoring (High, Medium, Low) that structures messy to-do lists into realistic daily time blocks with logical reasoning.
* **AI Research Assistant:** Generate structured executive briefs complete with core overview summaries, strategic insights, considerations, and follow-up questions.
* **AI Chat Assistant:** An embedded real-time conversational helper for fast workplace problem-solving, advice, and quick text drafting.
 
---
 
## 🛠️ Tech Stack
 
* **Frontend Framework:** React 18
* **Styling:** Tailwind CSS & Custom Design Tokens
* **Typography:** Space Grotesk, Inter, JetBrains Mono
* **Iconography:** Lucide React
* **AI Engine Integration:** Anthropic Claude API (`claude-sonnet-4-6`)
